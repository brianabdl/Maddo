# Writing style

Rules for any text an agent writes in this repo: prose in Markdown files,
code comments, doc comments, user-facing string literals, commit messages,
and PR descriptions.

## No em-dashes

Never use an em-dash (U+2014, the "—" character). Use a colon, a comma,
parentheses, or two separate sentences instead.

Older text in the repo still contains em-dashes. Leave those alone unless
you are already rewriting that passage for another reason.
